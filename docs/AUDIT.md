# Repository audit and baseline

Date: 2026-11-16
Branch: `master`
Upstream baseline: Caddy `v2.11.9`

This document records the state reviewed before the hardening changes and the
remaining boundaries. It is not a claim that every architecture or distribution
has been runtime-tested.

## Current pipeline

```text
config/build-matrix.json ─┐
config/plugins.lock.json ─┼─> build.yml resolve ─> 8 x xcaddy build
config/toolchain.json ────┘                         │
                                                    ├─> make-deb.sh (upstream .deb + SHA-512 check)
                                                    ├─> tarball + SHA-256 + build info
                                                    └─> GitHub Release (+ SBOM, lock, toolchain, matrix)
                                                              │
                                                              v
                                              make-apt-repo.sh (SemVer retention)
                                                              │
                                      Packages / Release / InRelease (fingerprint checked)
                                                              │
                                                              v
                                                     GitHub Pages + custom domain
```

## Confirmed and addressed

| Area | Previous state | Current state |
| --- | --- | --- |
| Plugin/toolchain locking | Workflow-only module paths; floating Go `stable` | `config/plugins.lock.json`, `config/toolchain.json`, exact `module@version` builds |
| Architecture matrix | Duplicated in workflow, script and docs | `config/build-matrix.json` consumed by workflow, APT script and CI |
| Release Latest pointer | `--latest` on every new release | SemVer comparison; old manual builds cannot take the Latest pointer |
| APT retention | GitHub release creation order | SemVer sorted retention; current release always included |
| APT completeness | Could publish partial indexes | Every APT architecture must exist before signing |
| GPG selection | First secret key in the keyring | Explicit `GPG_KEY_FINGERPRINT` variable; secret/public/expected keys must match |
| PR CI | No independent PR checks | `ci.yml`: static checks, amd64 package build, binary/module smoke test, signed APT test |
| Installer APT sources | Only two `.list` names | `.list` and Deb822 `.sources`, backups, conflict-safe restore |
| Uninstaller | None | `uninstall.sh` with dry-run, package preservation, source restore and explicit purge |
| Packaging provenance | md5sums/Installed-Size only | Upstream SHA-512 verification, lock/build info in the package, SBOM in Release |
| Documentation | No license/security/compatibility policies | `LICENSE`, `NOTICE`, `SECURITY.md`, `SUPPORT.md`, `THIRD_PARTY_NOTICES.md`, `docs/COMPATIBILITY.md` |
| Website | Single-file inline CSS/JS | Semantic HTML, separate CSS/JS/theme/i18n/field assets, dark default, SEO, robots/sitemap, OG card |

## Verified in this environment

- Debian 13 amd64: APT install, same-version `--reinstall`, modules, systemd,
  HTTP smoke test and custom domain (recorded 2026-11-15).
- Local static checks: `bash -n`, ShellCheck, actionlint, yamllint.
- Local packaging: upstream `.deb` SHA-512 verification, `.deb` inspection,
  locked module verification, signed APT generation with a temporary key, APT
  signature and Packages hash checks.
- Local site: desktop/mobile rendering, 390 px overflow check, dark/light
  themes, five languages, no-JS rendering and generated-site validation.
- GitHub Actions build/deploy runs from earlier revisions (see the Actions tab).

## Not verified

- Runtime execution of `arm64`, `armv7`, `armv6`, `armv5`, `ppc64le`, `riscv64`
  or `s390x` on target hardware.
- Installation on Ubuntu or Debian versions other than Debian 13 amd64.
- A full real installer run using the final hardened script on a fresh VM
  (dry-run and earlier install flows have been exercised separately).
- The GitHub artifact attestation and SBOM upload until the hardened workflow
  completes its first run.
- A real signing-key rotation.

These must not be reported as passing until actually executed.

## High-risk areas

- Replacing the official `caddy` package/APTs: same package name and version;
  the installer pin and `--reinstall` are required.
- GPG key management: the private key is outside the repository and the
  fingerprint is a repository variable; a mismatch intentionally blocks Pages.
- `pages/assets/` is copied recursively; a missing referenced asset fails
  `check-site.py` before deployment.
- The default theme is dark; stored light preference is applied before paint by
  `theme.js`.

## Deferred

- Multiple static pages (download/plugin/security/compatibility) and data files
  generated by CI.
- Docker images, multiple build profiles, custom plugin selection and a
  post-install diagnostic script (P3 in the task book).
- Full license audit of transitive Go dependencies; the CycloneDX SBOM is the
  authoritative dependency list, and direct modules are recorded in
  `THIRD_PARTY_NOTICES.md`.
