EasyCaddy

基于上游 Caddy 源码，加入 Cloudflare / 阿里云 / 腾讯云 DNS、限流、安全门户、四层代理、动态 DNS、WebDAV、缓存、GeoIP2 等插件的自用构建。

当前版本 v@VERSION@ 更新时间 @DATE@ 包名 caddy

一键安装

curl -fsSL @PAGES_BASE_URL@/install.sh | sudo bash

脚本会安装签名公钥、写入 APT 源、停用官方 Caddy 源，然后安装 caddy。可重复执行以升级。

手动安装（与官方方式一致）

sudo apt install -y debian-keyring debian-archive-keyring apt-transport-https curl
curl -1sLf '@PAGES_BASE_URL@/public.key' | sudo gpg --dearmor -o /usr/share/keyrings/easycaddy-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/easycaddy-archive-keyring.gpg] @PAGES_BASE_URL@/ ./" | sudo tee /etc/apt/sources.list.d/easycaddy.list
sudo chmod o+r /usr/share/keyrings/easycaddy-archive-keyring.gpg
sudo chmod o+r /etc/apt/sources.list.d/easycaddy.list
sudo apt update
sudo apt install caddy

包版本形如 @VERSION@-1+easycaddy，排序高于官方同版本包，因此会替换官方安装而不冲突。

升级 / 降级

sudo apt update && sudo apt install --only-upgrade caddy
apt-cache policy caddy
sudo apt install caddy=@VERSION@-1+easycaddy

站点保留最近 3 个版本；更早版本可在 GitHub Releases 下载 .deb。
