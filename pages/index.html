适用于希望自行管理软件源和密钥的场景。配置完成后，使用 --reinstall 确保替换为 EasyCaddy 构建。

sudo apt install -y debian-keyring debian-archive-keyring apt-transport-https curl

printf 'Package: caddy\nPin: origin "caddy.tatalvpai.vip"\nPin-Priority: 1001\n' | sudo tee /etc/apt/preferences.d/easycaddy
sudo chmod o+r /usr/share/keyrings/easycaddy-archive-keyring.gpg
sudo chmod o+r /etc/apt/sources.list.d/easycaddy.list
sudo apt update
sudo apt install --reinstall caddy

EasyCaddy 是 Caddy 官方发行版吗？

不是。EasyCaddy 是基于 Caddy 官方源码和 xcaddy 构建的非官方社区构建，附加精选第三方模块。项目与 Caddy 官方没有隶属关系。

已经安装官方 Caddy，还能直接切换吗？

可以。安装脚本会配置独立签名源、停用常见的官方 Caddy 源并写入 APT pin。由于包名和版本号与官方一致，脚本会在检测到已安装 Caddy 时使用 --reinstall 替换软件包。

插件版本是否固定？

默认不固定。每次构建会解析各插件仓库默认分支的最新版本。若需要可复现构建，可在工作流的 PLUGINS 清单中指定版本标签或 commit。

为什么 ARMv6 不在 APT 仓库？

上游将 ARMv6 与 ARMv7 的 .deb 都标记为 Debian 的 armhf 架构，同一索引无法容纳相同包名、版本和架构的两个包。ARMv6 构建仍会发布在 GitHub Release。

GeoIP2 模块安装后就能直接使用吗？

还需要自行准备 MaxMind GeoLite2 或 GeoIP2 数据库，并按插件文档配置数据库路径。
